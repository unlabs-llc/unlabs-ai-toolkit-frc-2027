# Getting help

**Last verified: 2026-09-11**

Support for this toolkit is community-only and best effort. Everything below reaches the same place,
and none of it comes with a response-time commitment. What that does and doesn't include is in
the [README](README.md#support), and it applies to everything below.

| You have | Go to |
|---|---|
| A question about using the toolkit | GitHub Discussions, in the Q&A category |
| Something that doesn't work | A new issue, using the bug form |
| A mistake in the documentation | A new issue, using the documentation form |
| A security problem | Not a public issue. See [SECURITY.md](SECURITY.md) |
| You don't use GitHub, or you'd rather not post in public | The service desk: https://unlabs.atlassian.net/servicedesk/customer/portal/1, or email frc-2027-toolkit@unlabs.atlassian.net |

## Knowing when there's a new release

- In projects installed with the supplied settings template, the toolkit tells you itself: when a
  Claude Code session starts, it checks for a newer release and says so, using the title from its
  most recent successful check (cached up to 24 hours).
- To be told without opening a session, **Watch** this repository, choose **Custom**, and tick
  **Releases**. Or subscribe to the release feed at
  `https://github.com/unlabs-llc/unlabs-ai-toolkit-frc-2027/releases.atom`.
